## 约定

- 默认串行放行；并行需用户确认范围且文件所有权不重叠。
- 已完结会话禁止再派新任务；一任务项一新会话。
- 遇阻 → 登记表状态 `blocked` + 简述原因，等主管调度。
- 裁决记录写 `rulings.md`（勿重开），下游任务书裁决带入区逐项引用。
- 登记表只由主管写入；实施只写回执（`{需求名}-{NN}-回执.md`）+ `log.md` 追加。
